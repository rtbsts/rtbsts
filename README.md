# Rita Bastos — Website

Portfolio site for [ritabastos.pt](https://ritabastos.pt).
Content is edited in **Pages CMS**, stored in this GitHub repository, and published automatically by **Cloudflare Pages**. Everything is free.

```
Pages CMS  ──save──▶  GitHub (this repo)  ──triggers──▶  Cloudflare Pages build  ──▶  ritabastos.pt
```

## Editing the site (day to day)

1. Go to [app.pagescms.org](https://app.pagescms.org) and sign in with GitHub.
2. Open this repository. In the sidebar you'll find:
   - **Case studies**: one entry per project.
   - **About page**: bio, experience, education and awards.
   - **Site settings**: name, description, contact details.
3. Edit and click **Save**. The live site updates in about 1–3 minutes.

### Case studies
- **Order** sets the position on the Home and Work pages. Lower numbers come first; using 10, 20, 30… leaves room to slot new projects in between.
- **Coming soon** lists the project without giving it its own page. **Hide from the site** keeps it saved but takes it off the site.
- **Gallery** is the list of rows, top to bottom. For each row, choose a **Row type**:

| Row type | Fill in |
|---|---|
| Full width image | Image |
| Two images side by side | Image + Second image |
| One image, half width | Image |
| Video (uploaded file) | Video file (MP4/MOV, short loops work best, no sound) |
| Vimeo video | Vimeo link or ID, plus the aspect ratio if it isn't 16/9 |

Upload images at full quality (JPG, PNG or GIF). They are optimised automatically: WebP in several sizes, GIFs turned into lightweight videos.

## How the build works

`build.py` reads `content/` and `originals/` and writes the finished site to `dist/`.
Processed images are stored in `optimised/`, so each image is only processed once. New uploads are processed during the Cloudflare build.

```
pip install -r requirements.txt
python3 build.py            # build into dist/
python3 build.py --clean    # rebuild everything from scratch
```

| Folder / file | What it is |
|---|---|
| `content/projects/*.json` | one file per case study (edited by the CMS) |
| `content/about.json`, `content/settings.json` | About page and site settings |
| `originals/` | original images and videos (CMS uploads go here) |
| `optimised/` | processed images, generated by the build |
| `assets/` | CSS, JS, fonts, favicon and server/security headers |
| `.pages.yml` | the CMS forms |

## One-time setup

### Cloudflare Pages
Workers & Pages → Create → Pages → Connect to Git → choose this repository, then:

- **Framework preset:** None
- **Build command:** `pip install -r requirements.txt && python3 build.py`
- **Build output directory:** `dist`
- **Environment variable:** `PYTHON_VERSION` = `3.12`

### Domain (ritabastos.pt, registered at dominios.pt)
1. In Cloudflare: Add a domain → `ritabastos.pt` → Free plan. Cloudflare shows two nameservers.
2. At dominios.pt, replace the domain's nameservers (DNS servers) with the two from Cloudflare. This can take a few hours to take effect.
3. In the Cloudflare Pages project → Custom domains → add `ritabastos.pt` and `www.ritabastos.pt`.

## Effects and where they live
- **Loader, reveals, hovers, cursor, smooth scrolling:** `assets/js/main.js` and `assets/css/main.css`.
- **"Ragged Edge" effect** (images widening near the bottom of the screen): `assets/js/edge.js`. It uses the same formula as raggededge.com. Without WebGL, or with "reduce motion" switched on, the site shows the normal images.
- **Security headers:** `assets/server/_headers` (Cloudflare) and `assets/server/.htaccess` (Apache hosting).
